# GBU Review: Backyard Barista Desktop UI & Game Loop
**Date:** 2026-10-28 | **Target:** `flutter_client/` & `ai_studio_lane_a/index.html` | **Lens:** Product & Desktop Game UI + Game-State Auditor (`gbu-lens-critic`)

## GOOD (Keep, do not touch)
- **3-Layer City Priority Resolution:** `Manual UI Override > Firebase Remote Config > Local Default` in `flutter_client/lib/config/city_edition_controller.dart:112-123` is deterministic and well-isolated.
- **2.5s Cloud Run HTTP Timeout & Offline Fallback:** `CafeJudgeService.evaluateOrder` (`flutter_client/lib/services/cafe_judge_service.dart:33-118`) enforces a hard `2500ms` timeout and falls back to `CafeReview.localFallback` without throwing unhandled exceptions on stage.
- **Injectable Clock for Deterministic Tests:** `CafeJudgeService` (`flutter_client/lib/services/cafe_judge_service.dart:14-18`) accepts `Clock Function()` instead of calling `DateTime.now()` directly.
- **Custom Vector Artwork for Gaziantep Round 2:** `CustomKatmerRollSvg` and `CustomIsotPepperSvg` (`flutter_client/lib/data/custom_svg_items.dart:10-226`) render crisp vector paths with zero external network dependencies.
- **Zero-Asset Procedural Web Audio Synthesizer:** `WebAudioCueSynthesizer` (`flutter_client/lib/services/sound_player_web.dart:6-135`) synthesizes grinder, espresso steam, counter bell, sad trombone, and level-up fanfare cues via Web Audio API oscillators and noise buffers.
- **192-Byte SVG Path Budget Guard:** `tool/rehearsal_3g_check.dart:24-66` verifies that the custom SVG path stays under the 250-byte live-stage paste budget.
