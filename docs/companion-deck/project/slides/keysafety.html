Before you deploy

A key baked into a web build is a public key.

Anything passed with --dart-define ends up in the JavaScript your browser downloads. For a public Lane B deploy, leave GEMINI_API_KEY out: the app runs on the offline judge. Use your key locally, or use AI Studio’s deploy, which keeps it server-side.

Production path: firebase_ai with App Check, or a small server proxy.

This is the one rule that protects your Google account after the workshop. The starter Dockerfile deliberately has no GEMINI_API_KEY build argument, so a plain gcloud run deploy from flutter_client never embeds a key. If you did embed one by accident, delete that key in AI Studio and create a new one.
