Pattern 3 · Quota math

Rate limits belong to the project, not the key

ONE SHARED PROJECT

300 → 1

300 builders share one free-tier bucket of roughly 5 to 15 requests per minute. HTTP 429 arrives within seconds.

ONE PROJECT EACH

300 → 300

Each builder brings a personal AI Studio key. One call per order means 1 to 2 requests per minute per player.

Never paste the speaker’s key into your app. Create your own in AI Studio in under a minute.

Free-tier limits are applied per Google Cloud project and change over time: check ai.google.dev/gemini-api/docs/rate-limits on the day. The workshop survives either way, because a 429 falls straight into the offline fallback from Pattern 2.
