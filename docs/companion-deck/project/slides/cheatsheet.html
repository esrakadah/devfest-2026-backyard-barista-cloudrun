Lane B cheat sheet

Five commands you will actually type

# run locally with your own key
flutter run -d chrome --dart-define=GEMINI_API_KEY=your_key
# run with no network at all
flutter run -d chrome --dart-define=OFFLINE_MODE=true
# pick a city edition
flutter run -d chrome --dart-define=DEFAULT_CITY=berlin
# check before you ship
flutter analyze && flutter test
# ship (no key baked in)
gcloud run deploy backyard-barista --source . --region europe-west1 --allow-unauthenticated

All commands run inside flutter_client/. City ids are berlin, gaziantep, adana and istanbul. On a deployed build, add ?remote_city=adana to the URL to try layer 2 of the config cascade without redeploying.
