Every network path has an exit

8 s

Live call timeout

After 8 seconds the Gemini request is abandoned, not awaited forever.

250 ms

Offline bundle load

mock_responses.json loads once and is cached per city.

Any error

Same review shape

Non-200, 429, bad JSON or no key: the game falls back and keeps playing.

Design rule: the fallback returns the same CafeReview type, so the UI never needs a special error screen.

Both durations are constants at the top of cafe_judge_service.dart. Force the fallback any time with --dart-define=OFFLINE_MODE=true, or simply leave GEMINI_API_KEY empty. The review object carries an isFromLiveGemini flag so you can still tell the two apart in the UI or in logs.
