Pattern 5 · Serverless ship

A stateless container on a public URL

Stage 1 · Build

The Flutter image compiles a release web build, baking in the city and model.

Stage 2 · Serve

nginx:alpine serves the files on port 8080, the port Cloud Run expects.

Scale to zero

No state on the server, so Cloud Run can add or remove instances freely.

LANE B · FROM flutter_client/

gcloud run deploy backyard-barista \
--source . \
--region europe-west1 \
--allow-unauthenticated

Lane A: press “Deploy to Cloud Run” in AI Studio instead.

Source: flutter_client/Dockerfile and prompts/step-3-deploy.md. The repo’s own warm benchmark against the live europe-west3 service measured 53.81 ms p50 for serving the app; that is static file serving, not the Gemini call. Lane A deploys through AI Studio, which keeps the API key on the server side.
