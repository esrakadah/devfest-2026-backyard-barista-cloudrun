Kulvar B komut kartı

Gerçekten yazacağın beş komut

# kendi anahtarınla yerelde çalıştır
flutter run -d chrome --dart-define=GEMINI_API_KEY=anahtarin
# hiç ağ olmadan çalıştır
flutter run -d chrome --dart-define=OFFLINE_MODE=true
# şehir seç
flutter run -d chrome --dart-define=DEFAULT_CITY=gaziantep
# yayına almadan önce kontrol et
flutter analyze && flutter test
# canlıya al (anahtar gömülmez)
gcloud run deploy backyard-barista --source . --region europe-west1 --allow-unauthenticated

Tüm komutlar flutter_client/ klasöründe çalışır. Şehir kimlikleri: berlin, gaziantep, adana ve istanbul. Yayındaki bir build’de adresin sonuna ?remote_city=adana ekleyerek ayar zincirinin 2. katmanını yeniden deploy etmeden deneyebilirsin.
